# CodeForge AI

CodeForge AI is an AI-powered codebase intelligence platform.

It allows developers to connect a GitHub repository,
search its code semantically, and ask AI-powered
questions about the codebase.

## Planned Features

- GitHub repository ingestion
- AST-based code parsing
- Intelligent code chunking
- Vector embeddings
- Semantic code search
- HNSW vector indexing
- RAG-based code understanding
- AI-powered debugging
- Automated test generation
- React dashboard
- Docker deployment
